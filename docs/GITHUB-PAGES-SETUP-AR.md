# تشغيل صفحة المشروع العامة عبر GitHub Pages

الصفحة الجاهزة هي `docs/index.html`. لا تحتاج إلى إطار JavaScript أو مكتبات خارجية.

1. ارفع `docs/index.html` إلى فرع `main` مع بقية ملفات الإصدار.
2. افتح مستودع `IsaacAmer/erdos-straus-research` على GitHub.
3. افتح **Settings** ثم **Pages**.
4. ضمن **Build and deployment** اختر **Deploy from a branch**.
5. اختر الفرع `main` والمجلد `/docs` ثم اضغط **Save**.
6. انتظر نشر GitHub Pages، ثم اضغط **Visit site** في صفحة Pages.
7. افتح الموقع من نافذة خاصة أو متصفح آخر للتأكد من أنه عام ويعمل.
8. حدّث رابط الموقع في README بعد أن يظهر العنوان الفعلي؛ لا تكتب رابطًا مفترضًا قبل نشره.

تنبيه: موقع GitHub Pages سيكون عامًا على الإنترنت. لا تضع فيه البريد الشخصي أو الاسم القانوني أو بيانات المدرسة أو أي معلومات لا تريد نشرها. صفحة GitHub Pages عامة حتى لو كان المستودع خاصًا في بعض الخطط، لذا افحص المحتوى قبل التفعيل.

الشرح الرسمي: https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site
