Research status: exploratory computational research. This project does not prove the Erdős–Straus conjecture, does not establish that the restricted Type-II exceptional set is empty, and makes no claim of confirmed priority for the Phase 14 density calculation.

What the project studies

Exact arithmetic and witness criteria

Python tools check selected Type-I and Type-II parameterizations, reconstruct witnesses, and verify identities using integer arithmetic.

Divisor and quotient searches

Bounded quotient-layer and small-factor searches are cross-checked on finite regression sets.

Character and Jacobi audits

Finite witness collections are checked against published Jacobi-symbol identities and selected square-class conditions.

Restricted density calculation

A Phase 14 note derives a restricted density corollary from an existing sieve theorem using a totient-selected family of parameters.

Mathematical scope

The classical conjecture asks whether every integer n ≥ 2 can be written as a sum of three unit fractions:

4/n = 1/x + 1/y + 1/z, with x, y, z positive integers.

The project's recent focus is a restricted Type-II divisor criterion for primes p ≡ 1 (mod 24), with 1 ≤ u ≤ 4 and an admissible parameter a. The Phase 14 note reports an upper bound for the set of primes that fail all such restricted witnesses.

Important limitation: a small exceptional-set bound does not prove that the exceptional set is empty. The density calculation is derived from an existing sieve theorem; the novelty of the specific application is not established.

Reproducibility

From the repository root, run:

python -m unittest discover -s tests -v

For a reproducible report, record the commit hash, exact Python interpreter, operating system, command, and full output. The repository's CI workflow should be merged and its green runs linked here once available.

Research integrity

  • Published criteria and sieve theorems are attributed to their sources.
  • Finite computation is labeled with its exact input range.
  • Derived results are distinguished from established literature.
  • Unresolved questions and corrections remain documented.
  • AI assistance is disclosed; it is not treated as a mathematical authority.
