# Primary sources used in Phase 2

1. Luigi Antonio Rosati, “Sull'equazione diofantea 4/n = 1/x1 + 1/x2 + 1/x3”, *Bollettino dell'Unione Matematica Italiana*, Serie 3, Vol. 9 (1954), no. 1, pp. 59–63. Digital scan: https://www.bdim.eu/item?fmt=pdf&id=BUMI_1954_3_9_1_59_0

2. Serge E. Salez, “The Erdős–Straus conjecture: New modular equations and checking up to N=10^17”, arXiv:1406.6307 (2014), Proposition 1 gives normalized Rosati equations. https://arxiv.org/abs/1406.6307

3. Benjamin Dahan, “Sieve dimension and search depth for the Erdős–Straus conjecture, n ≡ 1 (mod 24)”, arXiv:2608.24035v2 (2026). Theorem 2.6 and Corollary 2.7 give fixed-shift criterion; Theorem 3.9 and Lemma 3.10 give the two-parameter Type-II witness; Theorem 3.14 concerns Algorithm 2 correctness and complexity. https://arxiv.org/abs/2608.24035

4. Carl Pomerance and Andreas Weingartner, “Exceptions to the Erdős–Straus–Schinzel conjecture”, *Ramanujan Journal* 69 (2026), article 31, DOI: 10.1007/s11139-025-01312-2; arXiv:2511.16817. Corollary 2.2 gives Type I; Corollary 2.4 gives Type II. https://arxiv.org/abs/2511.16817

## Citation precision

- Do not cite Dahan Theorem 3.14 as a Type-I criterion. It proves correctness and an operation-count bound for Algorithm 2.
- The normalized Type-I witness system in the source note is a coordinate form connecting Rosati Type I and Pomerance–Weingartner Corollary 2.2. It should not be attributed to Dahan Theorem 3.14.
- Dahan Corollary 2.7 has a twisted fixed-shift branch identified as Type I and an untwisted branch identified as Type II.
