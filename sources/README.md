# Bibliography register

For each source, record:

- full bibliographic citation and stable URL/DOI;
- publication type (journal / preprint / proceedings / repository / web reference);
- exact theorem or claim used;
- assumptions and range;
- whether the claim has been independently checked;
- notes on corrections, errata, or later work.

Do not treat a preprint, AI-generated repository, or personal web page as an established theorem without inspecting its proof and publication status.
