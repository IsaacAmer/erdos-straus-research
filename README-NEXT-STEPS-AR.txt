   .\.venv\Scripts\python.exe -m unittest discover -s tests -v
3) إذا نجحت الاختبارات، نفّذ:
   .\.venv\Scripts\python.exe .\src\criteria_equivalence.py
4) أرسل المخرجات كاملة. لا تشغّل Git commit قبل مراجعة النتائج.
